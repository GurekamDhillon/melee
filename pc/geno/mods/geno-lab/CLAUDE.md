# geno-lab: the LAB mod (SOLO > LAB)

One Lua script, `scripts/lab.lua` (~5k lines), its art in `ui/` (generated by `art/lab_art.py`,
see `art/README.md`), and `mod.json`. The design and API are `docs/geno.md` section 14; each stage
(A-E, then D1-D5) has its own subsection saying what it built and what was measured.

## How lab.lua is organised

- The main chunk is at Lua's **200-local limit**. New work goes in its own function scope, as
  `stage_e()` and `stage_d()` do: `local LX = {}` outside, `local function stage_x() ... end
  stage_x()`, exporting through the table. Stage E exports `LE.*`, stage D `LD.*`.
- **Modes** are the `MODES` table: toggles (`t`, remembered in `settings.txt`) and actions (`a`,
  run through `ACTIONS[name]`, with `STATES[name]` for their on/off icon). Key `0` is mode 10.
- **The pause menu** is `TABS`; a tab's `items` is a table or a function returning one. Rows are
  `{label, icon, desc, value, run, adjust, toggle}`. Eight tabs fit; the strip narrows itself.
- **Hooks**: `on_tick` (keys), `on_frame` (after each game frame; not during re-simulation),
  `on_hit`/`on_land`/`on_action_change`/`on_hitlag` (queued engine events), `on_loadstate`
  (a load, a step back = 0, the library = 9), `on_hot_reload`, `on_draw`.
- **Drawing** is `gd.kit` only (`txt`, `stxt`, `quad`, `img`, `icon`, `panel`, `key_chip`);
  `gd.line`/`gd.fill` for world-space overlays. Colours are the palette constants at the top.
  Textures load on first draw: the preload at the top of `on_draw` keeps that under the 50 ms
  script budget. Nothing per-frame may re-measure text in a loop (cache, as `wrap` does).
- **Frames**: a move's frame 1 is the frame its state starts (`action_frame` 0), as the export
  and frame-data sites count. IASA is the flag *turning on* inside the state. The static script
  reading (`analyse`, FRAMES, the export's autocancel) may run a frame high: open question in 14.12.

## Before committing a lab.lua change

1. Syntax: any Lua 5.4 `luac -p` (or the harness below, which loads it).
2. `lua pc/geno/tools/lab_stage_d_check.lua pc/geno/mods/geno-lab/scripts/lab.lua`: all checks
   pass. Add a check for every bug fixed from an in-game run; it should fail on the old code.
3. It has not run in the game unless a Windows agent ran it: say so in the commit.

## Reading the game

`gd.player(port)` fields come from `gs_push_player` / `gs_push_lab_fields` in
`pc/platform/gw_script.c`. Everything is read-only except the documented gameplay writes
(`set_motion`, `set_percent`, `set_shield`, `input`, `mirror_pad`, the states), which are offline
only and fork the rewind timeline. Game constants come from `gd.lab_common()` (PlCo) and
`gd.attrs(port)`, never typed in.
