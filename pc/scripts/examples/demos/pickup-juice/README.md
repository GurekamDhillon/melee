# Pickup with juice

Offline vanilla FD LAB. Mount this mod at boot so its texture-free FX packages register.
I spawns a plain blue pickup; J spawns the same definition with presentation enabled;
R clears owned items and effects. Walk or jump into each pickup. Repeat J quickly to hear
70-cent streak steps; wait more than 90 logic frames to reset. Wait 900 frames to inspect
native expiry blink. Receiving HUD stripe flashes for 24 frames. Both sides use hover 6,
scale 2.5, spin 360 degrees/second, tilt 12 degrees; fallback visuals require no assets.
The plain side retains native blink because both sides deliberately use the same definition.

This demo is source/stub checked only. No build, game launch, sound audition or timing claim.
Generated main embeds `pc/scripts/lib/pickup_juice.lua`; rerun
`python tools/port/pickup_juice_demo.py` after changing that shared factory.
