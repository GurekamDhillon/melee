# Vanilla Hero

The Geno engine native Mario-reference fixture. Offline only.
Retail model, clips, effects and sounds are resolved from the user's disc. No disc data ships.
Walk speed is 1.8; jab 1 is an authored 12% root-bone hitbox.
All other states and scripts inherit the native Mario/common v1 preset.
An integrator rebuild and full-stock/LAB verification are required.
