## One DK file, traced (lunar2, Falcon p1 vs DK p2, first miss at slippi 48)

- Frame 48 is the first ThrownF frame (victim action 239, DK action 219 ThrowF, both at anim frame 1/1.04).
- `ftCo_800DB368` -> `lb_8000C1C0` puts a position constraint (RObj 0x90000001) on the victim's XRotN with DK's TransN2
  as target. `get_global_position` copies the target's `mtx[.][3]` exactly, and `ftCo_800DE508` then adds `x1A70` with
  `fmadds`. So the victim's position is DK's TransN2 world translation plus a fixed offset.
- An exact-f32 model of `PSMTXConcat`'s translation column (`tools/rust-port/slp/clusterF/joint_chain_ulps.py`)
  reproduces the engine's TransN2 bit for bit. Inverting the final `fmadds`, the recorded position needs TransN2 world
  x +1 ulp and y -3 ulp; no perturbation of DK's animated TransN2 translation gives both.
- **The Dolphin oracle agrees with the engine.** The desktop's oracle bone dump of the same file (port 2, slippi 46-48,
  frame end) has every joint of DK's TransN2 -> TopN chain bit-equal to the engine (R, S, T and world mtx; only the 0x40
  dirty bit differs on two joints), and the oracle's victim TopN x at 48 equals the engine's. Only the recorded
  Post-Frame differs (x 1 ulp, y 12 ulp).
- So deterministic playback of this file, on console code, gives the engine's value; the recording console computed
  something else. This is not a throw-math bug in the engine.

## Lead: online rollback on the recording console

3.19.1 replays are online games. Slippi writes a rolled-back frame again, so a .slp holds several Post-Frame events
for one frame (`slp_rollback_frames.py`). In the traced file, frame 48 is recorded twice (both copies hold the
divergent value) while 46 and 47 are recorded once. The game rolls back a lot overall (13416 of 20460 frame/port
records repeat), so one frame proves nothing. The open test is whether cluster F's first divergences fall on
rolled-back frames more often than the base rate (`rollback_vs_divergence.py`; started, stopped before it finished).
If they do, the mechanism to look for is what a resimulated frame does differently on the console (rendering is
skipped during a rollback, and headless runs keep the draw callbacks for JObj dirty propagation, merge 9193822eb).

The 3 Ice Climbers 3.19.1 files left as "1-ULP x/y (FMA class)" in slpcheck.md are likely the same class.
