# Zones

Load this gameplay script in an offline match on a broad flat stage. Three
outlines divide the gameplay plane into two rooms and a doorway. The readout
shows native membership and residence frames; the console logs enter, exit,
none and some events. The rooms have no physical walls or floors.

Stop at x=-12 and x=12, turn back in the doorway, dash through ten times,
then leave all three outlines and return. A stationary boundary should produce
one initial membership, without repeating events. Test Ice Climbers for sub-fighters.
Unload the demo to retire its owned zones.

Source and Lua checks only; game execution and visual acceptance are pending.
