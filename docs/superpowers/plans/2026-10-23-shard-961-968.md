# Shard 961–968 implementation plan

**Goal:** Port all PC definitions in the eight assigned baselib TUs and compare their behavior against native C with shipping float contraction.

**Architecture:** Re-export existing native implementations, adding adapters where the C interface requires them. New ports live in `melee_runtime::tu`; unresolved external functions have exactly named TODO hooks in each module's `ext`. All C records come from `melee_types` and retain generated GC metadata. Reuse the native LLVM oracle lowering and existing state-oracle infrastructure.

**Spec:** User shard request, `RUST_PORT.md`, inventory section 4, group-1 and group-runtime notes.

## Constraints

- Work exclusively in this worktree on `port/shard-961-968`; no push, merge, stash, disc data, or worktree removal.
- Every cargo invocation sets `CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 CARGO_INCREMENTAL=0`.
- Check every C function definition against existing code before writing a port.
- Verify outputs and state against native C, including call traces where external effects are hooks. Smoke tests do not establish equivalence.
- The root worker alone edits `tu/mod.rs` and shared type generation; workers own disjoint source/oracle files and do not commit concurrently.

- [ ] Particle renderer: `psdisp.c`, `psdisptev.c` → `src/tu/psdisp.rs`, `psdisptev.rs`; synthetic state + GX transcript oracle, including emitted vertex values and FMA sites.

- [ ] Integration: register each module once, complete generated types if needed, review every task, run `cargo build --workspace` and `cargo test -p melee_runtime`, then commit in small steps with the required coauthor line.

## Review focus

- FMA contraction and float-to-integer conversion must match oracle IR lowering.
- Bitfields compare logical values, not native C byte order.
- Pointer graph identity, nulls, callbacks and aliased inputs remain observable.
- Existing implementation reuse must not hide uncovered C definitions.
- New tests must compare real C execution, include meaningful branch coverage, and fail under a plausible mutation.
