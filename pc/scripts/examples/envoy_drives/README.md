# envoy_drives (original drive models for the Envoy mod)

Loot-drive models for `melee/pc/scripts/examples/envoy`: the floor pickup and the inventory-grid icon. **Every mesh
and every texel in this mod is original to this project and generated by `tools/make_drives.py`** (Python standard
library only; run `python tools/make_drives.py` to regenerate `models/`). Nothing is traced, converted or taken from
a game, a model file or another project; the shapes are plain geometry (pyramids, extruded polygons, an icosahedron)
and the textures are arithmetic colour ramps. An asset-only mod (`kind: misc`): no script.

Envoy loads these models (`drive_models.lua`: `V.MOD='envoy_drives'`). The earlier local-only `envoy_drives_sa2` models (Sonic
Adventure 2 assets, never shipped) are deprecated (owner, 2026-10-07): nothing loads them, and the release guards still refuse them.

## Files (`models/`)

| file | what | triangles |
|---|---|---|
| `drive_red`, `drive_green`, `drive_blue`, `drive_yellow`, `drive_purple`, `drive_white` | one body per family | 24, 48, 60, 80, 68, 28 |
| `drive_glass` | the translucent shell Envoy draws over every floor drive (alpha, `glass` material) | 20 |
| `drive_ring_magic`, `drive_ring_rare`, `drive_ring_unique` | optional rarity overlays (see below) | 74, 146, 106 |
| `drive_atlas.gxtex`, `drive_atlas.glow.gxtex` | 128x128 shared colour + glow atlas (every model uses it) | |
| `*.coll.json`, `*.material.json` | no collision; `lit` + emission, `glass` for the shell | |

Every body is centred, fits a 4.4 world-unit box (about as wide as tall), so it fills a square cell and rests on the
floor with Envoy's `LIFT = 2.6` at `SCALE = 1.15`.

## Design

One family of small emblems: **a dark, saturated body with bright emissive seams or a hot core**, so it reads at 48 px
on a dark or a bright background. Colour carries the family and so does SHAPE (colour-blind players):

| family | meaning | shape | why |
|---|---|---|---|
| red | damage | six-spoked spike jack (caltrop): sharp points on every axis | angular, edged, a thing that hurts |
| green | speed | two forward chevrons, bevelled, glowing edges | streamlined, directional, "go" |
| blue | defence | faceted heater shield with a raised glowing boss | the plain shield form, layered facets |
| yellow | air / jump | a swept fan of six feathers (two wings) rising from a hot core | winged, upswept |
| purple | status | a faceted spore orb ringed by six bulbs of different sizes | a spore / bubble cluster, round and lumpy |
| white | wild | one lopsided jittered gem, every face a different spectral colour, two shards | irregular and prismatic |

Silhouettes in order: four-point star, double chevron, shield, fan, bubble-ringed orb, shard gem. They stay distinct in greyscale.

### Rarity

Rarity is an **added element, not a new body**: a second model drawn on top of the family model with the same pose
(`gd.kit.model` twice with the same rectangle and options; or a second `gd.model_spawn` at the same transform on the
floor). The overlays carry the bodies' bounds (zero-area padding triangles), so the screen auto-fit gives them the
same scale. Draw the overlay FIRST in a cell so the ring passes behind the body.

- common: nothing
- magic: one cyan ring around the middle
- rare: two violet rings above and below the middle
- unique: a gold ring with a crown of eight points

The overlays are optional: an Envoy that ignores them still works and shows rarity by its cell border and beam.

### Glow

The glow atlas is added unlit before the light (screen models) or as a TEV stage (world models). Each atlas row is a
ramp from a dark body to a bright emissive colour; a vertex picks its place on the ramp through `u`, so seams and
cores glow and the body stays dark. Rows exist for each family's body and "hot" colour, six spectral rows for the
white drive, three rarity colours and a glass row.
