# Fighter action restrictions

Offline LAB demo. Load this folder, then enter a match with P1 and an opponent. Initial setup runs on the first active frame, including loading during a match.

F: next forbidden action; R: allow all actions. The HUD reads native state. Refusals are shown rather than claimed as success.

Syntax checked only; no build or game run has been performed.

Restriction booleans mean true = forbid, false = allow. F forbids one action at a time.
