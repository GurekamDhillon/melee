# Gameplay prior art

Project M / Project+ Turbo mode informed the native interrupt-window match rule:
credit the Project M Development Team and the Project+ team. The source consulted
in the project research was [ProjectMCodes Turbo.asm](https://github.com/Fracture17/ProjectMCodes/blob/master/GCTRM/Source/ProjectM/SpecialModes/Turbo.asm),
whose header credits Magus, Dantarion, standardtoaster and DukeItOut.

UnclePunch's **Melee Turbo Mode Replaces Single Button Mode**, for 20XX, is prior
art for a timed hit-confirm interrupt window. Its implementation was not available
for inspection in the research; the reported 40-frame and hitlag behavior is not
claimed as verified or reproduced here.

These are acknowledgements of ideas. No Project M, Project+, or UnclePunch code
was copied. The port's native rule implementation is original. The in-game
Credits screen also acknowledges both sources.
